# TruchiCount

Prototipo inicial para una app de gastos compartidos de pareja, inspirada en Tricount y pensada para el día a día del departamento.

## Qué incluye hoy

- Vista principal con grupos mensuales.
- Detalle del mes con tabs de gastos, saldos y tickets.
- Botón flotante para cargar gasto rápido.
- Modal con dos caminos: carga manual o escaneo de ticket.
- Demo visual del flujo OCR para detectar comercio, fecha y total.

## Stack base

La primera iteración está hecha en HTML, CSS y JavaScript vanilla para poder avanzar aunque el repo arrancó vacío y sin dependencias instaladas. Esto nos deja una base rápida para validar UI y flujo de producto antes de migrarlo a React, Expo u otra arquitectura.

## Próximos pasos sugeridos

1. Pasar este prototipo a un stack de app real.
2. Definir contratos backend para OCR, gastos, grupos y balances.
3. Conectar cámara o subida de imágenes.
4. Implementar persistencia y autenticación simple de pareja/hogar.
